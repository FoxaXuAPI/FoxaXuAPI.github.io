新分支首个版本 Coral 1.0 Geranium Build 13001
修复了LogonUI在处理登录失败时的事件处理策略
修复了OOBE在处理多个旧版用户的时候没有与usermgr同步

新增库 CO_USERSTATUS_LIB 用户架构更新，新增虚拟用户功能
此版本将Local Driver Security User变成了虚拟用户，不再存在与config/USERS,所创造的虚拟用户只能由内核API注销，自带内核保护，与SYSTEM用户共享配置文件，策略与安全配置
既此版本后再无除SYSTEM后的任何虚拟用户
修复了用户页面的部分问题， 修复了nativeshell 用户管理模块错误地直接修改PROFILE变量导致用户配置出错的问题，USERSVC不再因为用户界面的重载请求而重新加载整个用户
ntvlogon正式改名为crologon，同时新增svcvuc组件用于自动处理虚拟用户，crologon现添加了镜像检查，当用户配置文件出错时 USERSVC会自动进行重新加载，为稳定性考虑，此后不再提示配置文件错误而是直接重载。

由于此版本修改的内容过多，可能导致无法料到的问题，请及时关注我们的更新，以便随时解决棘手的问题。
